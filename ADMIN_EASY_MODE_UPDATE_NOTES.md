# Yard Loop Admin Easy Mode Update

This version makes the admin page easier to understand and use.

## Added
- A guide box at the top of every admin tab explaining what that tab controls.
- Clear page/category context, such as Hero, Services, Gallery, Contact, Brand, Leads, Pages, and Advanced.
- Style panels now say exactly which text field is being styled.
- Image fields now have direct photo upload controls instead of only raw URL boxes.
- Image fields show a preview of the current picture.
- Image upload fields explain what picture they control.
- After choosing a photo, the admin tells you to click Save to Blob to make it live.

## Important Use Steps
1. Open /admin.
2. Enter admin password.
3. Pick the correct tab.
4. Change wording, style, or upload photo.
5. Click Save to Blob.
6. Refresh the live page.

## Image Types
Best options:
- PNG for logo and transparent graphics.
- JPG or WEBP for photos/backgrounds.
- SVG for icons/logos if supported.
