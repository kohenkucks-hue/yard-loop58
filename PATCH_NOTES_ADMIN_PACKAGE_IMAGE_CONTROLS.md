# Yard Loop Patch — Admin Package + Image Controls

Patch-only update built from the latest patched Yard Loop ZIP in this chat.

## Changes made

- Added a clearly visible admin control in **Admin → Home Hero**:
  - Show/hide blue box behind the homepage hero image.
  - Homepage hero image crop/position selector.
  - Default website image crop/position selector.

- Kept the same controls in **Admin → Brand & Design** so they are available in both common places.

- Added admin controls in **Admin → Get My Plan / Pricing → Get My Plan Packages**:
  - Edit package names.
  - Edit package descriptions.
  - Edit each included service.
  - Add new services to each package.
  - Remove services from each package.
  - Show/hide each package card.

- Updated the homepage package section to use the same admin-controlled Get My Plan package data instead of hardcoded package services.

## Not changed

- No estimator pricing logic changed.
- No email routes changed.
- No lead form API changed.
- No contractor/customer page logic changed.
- No Vercel Blob save system changed.
- No service pricing bank changed.
